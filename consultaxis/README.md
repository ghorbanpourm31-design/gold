# ConsultAxis website

Bilingual (German / English) website for **ConsultAxis UG (haftungsbeschränkt)** — *Success Along Every Axis.*
Two divisions: **Business Consulting** and **Real Estate Consulting** (consulting only, no brokerage).

- Static pages, generated by a small build script with no third-party packages.
- No cookies, no tracking, no external requests: fonts, images and scripts are self-hosted.
- One server script (PHP) for the contact form. It sends an email and stores nothing.
- Before launch, read [`TECH-INVENTORY.md`](TECH-INVENTORY.md): every service, cookie and data flow for the legal review, plus the launch checklist.

## Quick start

Requires Node.js 18+ for the build. PHP 8 for local preview of the form. ffmpeg + curl to download photographs.

```bash
npm run build      # -> dist/
npm run images     # download + optimise the photographs, then rebuild
npm run serve      # preview at http://127.0.0.1:8080 (PHP built-in server)
npm run check      # links, headings, hreflang, external requests, launch blockers
```

## Structure

```
site.config.mjs          company facts, languages, URL slugs, navigation, hosting, consent services
content/de.json          all German copy (primary language)
content/en.json          all English copy
content/legal/<lang>/    Imprint and Privacy Policy (HTML with {{tokens}} filled from the config)
content/images.json      photograph slots: source, photographer, licence, alt text per language
src/templates.mjs        page templates
src/assets/              CSS, JS, self-hosted font, icons, downloaded photographs
public/                  .htaccess and the contact-form script (copied into dist/)
scripts/                 image download, launch check, preview router, browser test
dist/                    the finished website: upload this folder's contents
```

URLs: `/de/…` and `/en/…` with translated slugs (e.g. `/de/immobilienberatung/` and `/en/real-estate-consulting/`), `hreflang` and `x-default` on every page, a sitemap with language alternates, and a language switch that stays on the same page.

## Editing content

- **Text:** edit `content/de.json` / `content/en.json`, then `npm run build`. Keep both languages in step.
- **Company details** (address, managing director, register, VAT ID, phone): fill in `site.config.mjs → company`. Imprint and Privacy Policy in both languages update automatically. Empty fields show as highlighted placeholders, and `npm run check` lists them. The phone number appears on the contact page only once it is set.
- **Hosting / mailbox provider:** `site.config.mjs → hosting` and `mail`, used by the Privacy Policy.
- **After the legal review:** replace the legal HTML with the approved wording, then set `legalDraft: false` to remove the draft notice.
- **Photographs:** each slot in `content/images.json` names its source, photographer and licence. A file saved as `content/photos/<slot>.jpg` (or .png/.webp) always wins over the download: use this for ConsultAxis's own photography and for the slots marked `manual` (Unsplash blocks scripted downloads, so save those via its "Download free" button). Then run `npm run images`. Check every `reviewAlt` alt text against the downloaded picture. Pages show a light line-pattern stand-in until a photo exists.
- **Logo:** the wordmark and axis mark in `src/templates.mjs` (`mark()`) and `build.mjs` (favicon) are placeholders for the official logo.

### Adding a language

1. Copy `content/en.json` to `content/<code>.json` and translate it (professionally, not machine-only).
2. Add `content/legal/<code>/imprint.html` and `privacy.html`, consistent with the approved German version.
3. Add `{ code, locale, label, short }` to `languages` in `site.config.mjs`, and a slug for `<code>` in every route.
4. Add alt texts for `<code>` in `content/images.json` (English is used as fallback).
5. `npm run build`. Navigation, language switch, hreflang and sitemap pick it up. No template changes needed.

### Adding an optional service (analytics etc.)

Do this only after updating the Privacy Policy. Register the service in `site.config.mjs → consent.services` with category, provider, location, purpose, cookies and the script to load. The built-in consent manager then shows the banner (equal Accept / Reject buttons, everything off by default) and loads the script only after consent. Raise `consent.version` whenever the list changes.

### CMS

The brief asks for independent editing. The content is already split into plain JSON and HTML files per language, so a Git-based CMS (for example Decap CMS or Sveltia CMS) can sit on top without touching the templates. It is **not included yet**: its login backend adds a provider that would have to appear in the inventory, so choose it together with the host.

## Deployment

1. `npm run images && npm run build && npm run check`
2. Upload the **contents** of `dist/` (including the hidden `.htaccess`) to the web root of the host.
3. Point both consultaxis.de and consultaxis.me at the host. `.htaccess` redirects everything to `https://www.consultaxis.de` and forces HTTPS.
4. Make sure PHP 8 is active and `mail()` can send from `website@consultaxis.de` (create that sender or allow it with the host; SPF/DKIM for the domain help deliverability). Send a test enquiry in both languages.
5. Check the response headers (Content-Security-Policy, HSTS) and that `/api/contact-config.php` returns 403.

**nginx** equivalent of the `.htaccess` rules:

```nginx
server {
  server_name www.consultaxis.de;
  root /var/www/consultaxis/dist;
  index index.html;
  error_page 404 /404.html;
  location = / { if ($http_accept_language ~* ^en) { return 302 /en/; } return 302 /de/; }
  location = /api/contact-config.php { return 403; }
  location ~ ^/api/contact\.php$ { include fastcgi_params; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; fastcgi_pass unix:/run/php/php-fpm.sock; }
  location / { try_files $uri $uri/ =404; }
  add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
  add_header Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; form-action 'self'; frame-ancestors 'none'; base-uri 'self'; object-src 'none'; upgrade-insecure-requests" always;
  add_header X-Content-Type-Options nosniff always;
  add_header Referrer-Policy strict-origin-when-cross-origin always;
  add_header X-Frame-Options DENY always;
}
server { server_name consultaxis.de consultaxis.me www.consultaxis.me; return 301 https://www.consultaxis.de$request_uri; }
```

## Design notes

- Brand colours: Navy `#142B45`, Light Grey `#F4F5F6`, Champagne Gold `#B69A69`, White. Following the redesign brief, white and light grey carry the page; navy is for type, the primary button and small details; gold for fine lines, icons and small labels (as text only in the darker `#7A6238`, 5.3:1).
- One typeface (Geist, self-hosted), one radius, one button pair, one link style. Main pages open with a split hero (copy and photograph) over an animated "axis field".
- **Motion** (`src/assets/js/site.js`, `site.css` → MOTION):
  - background: a canvas behind every opening section and closing card draws a faint grid, gold axes through an origin point, pulses running outwards, slow ripple rings, and follows the pointer slightly. It pauses off-screen and in hidden tabs.
  - entrance: hero text rises in a 90 ms stagger, the photograph is revealed with a wipe, the gold axis lines grow from their origin.
  - scroll: headings, list items, cards, steps and rows rise in as they enter (70 ms stagger, capped); photographs wipe in; the axes diagram and the floor plan draw their lines.
  - interaction: buttons press (`scale(.97)`), arrows nudge, underlines draw, linked panels lift 2px and their photos zoom 1.03. Hover effects only on real pointers.
  - With `prefers-reduced-motion`, all of it is off and the canvas shows one still frame. Without JavaScript, everything is visible.
- Real estate pages present analysis and structure (floor-plan drawing, spec-sheet service lists, a clear limits panel) rather than property listings.
